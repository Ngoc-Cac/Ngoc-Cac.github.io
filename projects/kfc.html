Application of Big Data Frameworks for Sentiment Analysis of KFC reviews

This project applies Big Data technologies to ML workflows, specifically for sentiment analysis of Google Maps reviews across multiple KFC locations in Ho Chi Minh City.

Our group managed to orchestrate a distributed data platform that integrated HDFS and Spark to storing and processing crawled reviews from Google Maps. We also developed models for sentiment analysis and performed exploratory analysis of the crawled reviews.

Tech Stack: Docker, Apache Hadoop, Apache Spark, Python, Selenium, PySpark, PyTorch, Matplotlib

For me, this project was an adventure, because I got to learn several new tools and how some components work under the hood. For instance, I spent quite some time working with Docker, where most of the environment setup involved a lot of digging through documentation to get everything working properly. This was drastically different from the usual plug-and-play workflows that I was used to.

While I was familiar with PyTorch at that point in time, making the model training pipeline work with the processed data coming from Spark was new territory for me. The biggest challenge was leveraging everything that PySpark provides (distributed operations, lazy computation, etc.) while still preserving the efficiency of the training pipeline.

Regarding the models we have developed, we used a pre-trained PhoBERT model to extract features from the tokenized reviews. From there, we used a logistic regression classifier and a basic multi-layer perceptron as prediction heads to obtain the sentiment predictions.

We found that both models recognised negative and positive reviews fairly well, achieving an F1 score of around 80-90%. However, performance dropped significantly for "neutral" reviews. This was largely due to our assumption that all 3-star reviews were neutral, which was not the case as they were either mostly positive or mostly critical.
