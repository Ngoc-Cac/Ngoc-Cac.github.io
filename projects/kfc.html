Application of Big Data Frameworks for Sentiment Analysis of KFC reviews

This project applies Big Data technologies to ML workflows, specifically for sentiment analysis of Google Maps reviews across multiple KFC locations in Ho Chi Minh City.

Our team managed to orchestrate a distributed data platform that integrated HDFS and Spark to handle crawled reviews from Google Maps. We also developed models for sentiment analysis and performed explorative analysis of the crawled reviews.

Tech Stack: Docker, Apache Hadoop, Apache Spark, Python, Selenium, PySpark, PyTorch, Matplotlib

For me, this project was an adventure, because I got to learn a lot of new tools and how they work under the hood. For instance, I spent quite some time working with Docker, where most of the environment setup involved a lot of digging through documentation to have everything working. This was something very different from the usual plug-and-plays workflow that I was used to.

While I was familiar with PyTorch at this point in time, making the model training pipeline comminuicate with the processed data coming from Spark was a new territory for me. The biggest challenge was leveraging everything that PySpark provides (HDFS MapReduce, lazy computation, etc.) while still preserving the efficiency of the trainig pipeline.

Regarding the models that have developed, we used a pre-trained PhoBERT to extract features from the tokenized reviews. From there, we used a Logistic Regressor and a basic Multi-layer Perceptron to perform the predictions.

We found that both models recognised negative and positive reviews fairly well, with roughly 80-90% accuracy. However, performance dropped significantly for "neutral" reviews. This was largely due to our assumption that all 3-star reviews were neutral, which was not the case as they were either mostly positive or mostly critical.
